## 🌟 Sobre este proyecto

Este proyecto corresponde a un taller práctico de introducción a **React** donde trabajamos los conceptos iniciales de **componentes** y **props**.

La aplicación recrea una sección de testimonios inspirada en freeCodeCamp, mostrando información de distintos estudiantes y profesionales del sector tecnológico.

### Objetivos trabajados

* Creación de componentes reutilizables.
* Paso de datos mediante **props**.
* Organización del proyecto siguiendo principios de **Clean Code**.
* Maquetación responsive.
* Separación clara entre estructura, estilos y datos.
* Publicación del proyecto en GitHub.
* Despliegue en Vercel.

Este proyecto representa uno de mis primeros desarrollos completos con **React**, realizado de forma autónoma como parte de mi formación en **Desarrollo Web Full Stack e Inteligencia Artificial**. 🚀

## ▶️ Cómo ejecutar el proyecto en local

### 1. Clonar el repositorio

```bash
git clone TU-URL-DEL-REPOSITORIO
```

### 2. Entrar en la carpeta del proyecto

```bash
cd nombre-del-proyecto
```

### 3. Instalar dependencias

```bash
npm install
```

### 4. Levantar el servidor de desarrollo

```bash
npm run dev
```

La aplicación estará disponible en:

